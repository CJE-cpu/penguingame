# 남극 펭귄의 물고기 모험

## 바로 실행

Windows에서 `pygame/AntarcticPenguin.exe`를 더블 클릭하세요. Python 설치 없이 실행되며 이미지가 포함되어 있습니다.

소스로 실행하려면 저장소의 최상위 폴더에서 다음 명령을 사용하세요.

```powershell
python -m pip install -r requirements.txt
python pygame/main.py
```

## 목표와 조작

물고기 30마리를 모으고 아기 펭귄 3마리를 이글루로 데려온 뒤, 빙붕 탈출 도전을 완료하고 마지막 보금자리로 돌아오면 성공합니다. 잠수 탐험, 일지 수집, 집 꾸미기는 선택입니다. 걷기는 8프레임으로 약 1초에 한 주기를 재생하며, 가속 중에도 과하게 빨라지지 않습니다.

- Enter / 스페이스바 / T: 튜토리얼부터 시작
- N: 시작 화면에서 바로 모험, 또는 튜토리얼 건너뛰기
- 설명창의 Enter / 스페이스바: 설명 확인 (확인 키는 점프에 적용되지 않음)
- ← → / A, D: 이동
- 스페이스바 / ↑ / W: 점프
- ↓ / S + 이동: 배로 미끄러지기 (낮은 자세, 이동 속도 1.35배)
- E: 주변 친구, 잠수 구멍, 동굴, 깃발 및 보금자리와 상호작용
- TAB: 탐험 일지/연구 의뢰 열기·닫기 (모험 일시정지), 열린 상태의 ← → / A D: 페이지 넘기기
- 잠수 중 방향키 / WASD: 수영, 스페이스바: 위로 수영
- 성공 화면 Enter: 계속 탐험하며 집 꾸미기와 일지 수집
- R: 전체 진행을 초기화하고 설명 화면으로 돌아가기
- Esc / 창 닫기: 게임을 정지하고 종료 확인창 열기. ← →로 선택 후 Enter로 확인하거나 버튼을 클릭하세요. 기본 선택은 계속하기이며, Esc / N은 취소, Y는 종료합니다.

## 튜토리얼과 설명창

별도의 1,700픽셀 연습 해안에서 걷기, 점프, 낮은 통로 활주, 친구 동행과 이글루 구조, 일지 읽기, 수영과 귀환을 순서대로 연습합니다. 연습 바다에는 산소 제한과 적이 없습니다. 튜토리얼을 마치면 점수와 물고기 기록을 초기화하고 본편으로 이동합니다.

새 조작 설명은 화면을 정지한 설명창으로 안내합니다. 설명창을 확인하기 전에는 플레이어, 적, 아이템 효과, 산소, 탈출 시간이 모두 멈춥니다. 본편에서도 처음 사용하는 조작과 처음 만나는 탈출 도전, 집 꾸미기를 안내합니다. 활주는 낮게 누운 몸과 움직이는 날개로 표현됩니다.

## 추가 탐험

- **잠수**: 해안 첫 이글루 오른쪽의 넓은 눈밭 끝에 있는 얼음 구멍에서 E를 누르세요. 1,800픽셀의 바닷속에서 보너스 물고기 6마리를 찾습니다. 산소는 35초이며 왼쪽 위 구멍에서 E로 귀환합니다. 날개를 젓고 발을 차는 수영 모션과 기포가 표시됩니다. 산소가 다 떨어지면 체크포인트로 복귀하지만 모은 점수와 먹이는 유지됩니다. 친구와 동행 중에는 잠수할 수 없습니다.
- **구조 미션**: 빙하 친구는 옆에서 활주하여 얼음 껍질을 깨세요. 눈보라 친구는 E로 먹이 3마리를 나눠 주세요. 보금자리 친구는 같은 위쪽 옆길의 깃발 레버에서 E를 누른 뒤 만나세요. 각 미션 완료 후 친구와 함께 이글루에 가면 구조됩니다.
- **탐험 일지**: 각 구역 두 번째 위쪽 발판의 일지 1개씩, 총 6개가 있습니다. 하나당 60점이며 TAB으로 열고 ← →로 페이지를 넘깁니다. 친구의 위치와 해결법, 보물 위치, 지름길, 위험 요소와 조작 요령이 자세히 적혀 있습니다. 7번째 페이지는 연구 의뢰입니다.
- **동굴 지름길**: 동굴 입구에서 E를 누르면 해당 구역의 높은 옆길로 이동합니다.
- **보금자리**: 물고기를 주우면 점수와 별도로 먹이가 1마리 늘어납니다. 마지막 이글루에서 E로 둥지(5마리), 깃발(8마리), 꽃밭(10마리)을 차례로 만듭니다. 구조한 친구들은 집 주변에서 걸어 다닙니다. 사용한 먹이는 물고기 수집 기록과 점수를 줄이지 않습니다.
- **빙붕 탈출**: 다섯 번째 구역 입구에서 시작하여 32초 안에 오른쪽 끝에 도달하면 200점과 탈출 완료 기록을 받습니다. 시간 초과나 추락 후에는 다시 도전할 수 있습니다. 마지막 보금자리에서 수집과 구조를 마쳤지만 탈출 기록이 없다면 E로 도전 입구에 돌아갑니다.
- **빙하 결정**: 각 구역 높은 옆길의 푸른 결정을 하나씩 모으세요. 총 6개이며 하나당 40점입니다. 모은 결정은 추락과 피격 이후에도 유지됩니다.
- **연구 의뢰**: 수중 물고기 3마리 조사(100점·먹이 2개), 일지 3개 복원(150점·먹이 3개), 결정 6개 조사(250점·먹이 5개)가 있습니다. 목표를 달성한 뒤 아무 이글루 근처에서 E로 보상을 한 번씩 받습니다. 마지막 이글루에서는 의뢰 보상을 먼저 지급한 뒤 집 꾸미기를 진행합니다.

먹이, 일지, 결정, 연구 의뢰 보상, 구조 미션, 집 장식 및 완료한 탈출 기록은 체크포인트 복귀 시 유지됩니다. R로 새 게임을 시작하면 모두 초기화됩니다. 진행 저장은 실행 중인 게임에만 적용됩니다.

## 여섯 탐험 구역

10,800픽셀의 맵을 서로 다른 지형과 배경으로 구성했습니다. 구역당 1,800픽셀로 기존보다 50% 확장했으며, 물고기 30마리·적 12마리·물약 5개의 개수는 유지해 이동 중 이벤트 빈도를 줄였습니다.

1. 눈 덮인 해안: 파도와 바닷길, 순찰하는 게와 돌진 물범
2. 미끄러운 빙하: 높이가 다른 얼음 섬, 관성, 물범과 점프하는 얼음 정령
3. 얼음 동굴: 어두운 내부와 펭귄 주변 탐험 조명, 정령과 보물
4. 눈보라 고원: 강약이 변하는 돌풍, 높이 오르내리며 비행하는 도둑갈매기
5. 갈라진 빙붕: 무너지는 발판 다리, 빠른 정령과 물범
6. 펭귄의 보금자리: 갈라지는 위쪽 경로와 마지막 구조 목표, 이글루 주변 안전지대

얇은 발판은 아래에서 통과하고 위에서 착지할 수 있습니다. 이글루에 닿으면 현재 플레이의 복귀 지점이 저장됩니다. R을 누르거나 게임을 종료하면 진행이 초기화됩니다.

## 아이템과 점수

- 물약은 전체 맵에 5개(성장 2개, 가속 2개, 반전 1개)입니다. 획득 시 한 가지 효과만 적용되며, 다른 효과는 종료됩니다.
- 초록 성장 물약: 해안과 빙붕에 배치됩니다. 8초간 외형이 부드럽게 1.5배 커지고 접촉한 적을 물리칩니다. 이동 판정은 동일하므로 좁은 구간에서도 끼지 않습니다. 시간이 끝나면 1.5초 무적과 파란 보호 고리가 발동합니다. 이미 더 긴 무적 시간이 있다면 유지합니다.
- 노랑 속도 물약: 빙하와 눈보라 구역의 위쪽 옆길에 배치됩니다. 8초간 이동 속도 1.6배입니다.
- 보라 반전 물약: 동굴의 오른쪽 위 옆길에 1개 배치됩니다. 8초간 좌우 이동 반전이며, 중복 획득 시 방향은 유지하고 시간만 갱신합니다.
- 주황 물고기 10점, 파랑 25점, 황금 50점
- 게 처치 30점, 물범 40점, 도둑갈매기 45점, 얼음 정령 50점, 아기 펭귄 구조 100점, 동굴 보물 100점

물약 획득 시 회전하며 퍼지는 반짝임과 떠오르는 물약 아이콘이 나타납니다. 성장은 크기 변화와 나선 입자, 가속은 움직이는 잔상과 번개, 반전은 회전하는 화살표로 표현됩니다. 시간 막대도 확인할 수 있습니다. 물범은 경고 표시 후 짧게 돌진합니다. 모든 적은 위에서 밟거나 성장 효과로 물리칠 수 있습니다.

아기 펭귄은 빛기둥, 점멸하는 바닥 고리, 반짝임과 위쪽 화살표로 표시됩니다. 방향 안내와 미니맵에서도 친구 위치를 확인할 수 있으며, 동행 중에는 가장 가까운 이글루 방향을 안내합니다.

만난 아기 펭귄은 뒤에서 몸을 흔들며 걷고, 플레이어가 지나간 점프 경로를 따라옵니다. 멈추면 약간 떨어진 자리에서 기다리며 이글루에 도착하면 구조가 완료됩니다. 추락하거나 피격되어 돌아오면 친구는 원래 위치로 돌아갑니다.

적은 처치 시 납작해졌다가 회전하며 사라집니다. 펭귄은 처치 순간 몸이 짧게 눌리고, 피격 시 붉게 깜박이며 뒤로 젖혀집니다. 피격 모션이 끝나면 저장 지점으로 복귀합니다. 동굴과 이글루는 실제 발판 높이에 맞추고 밑부분을 눈에 살짝 묻어 표시합니다.

물약은 물고기, 친구, 이글루, 동굴 및 적의 순찰 범위와 겹치지 않는 위치에 배치됩니다. 배경은 넓은 한 장의 이미지를 이동하며 구역 사이를 부드럽게 혼합하므로 이미지 양쪽 끝의 연결선이 나타나지 않습니다.

미끄러운 얼음에서는 관성이 남고, 눈보라 구역의 바람은 왼쪽으로 밀어냅니다. 금이 간 발판은 밟으면 점점 강하게 흔들리다가 0.8초 뒤 무너지고 4초 뒤 복구됩니다. 흔들림은 표시만 바꾸므로 붕괴 전 발판의 이동 판정은 유지됩니다.

추락이나 피격 시 마지막 이글루로 돌아오며 점수는 유지됩니다. 아이템 효과는 사라지고 2초간 무적이 됩니다. 구조 중인 아기 펭귄은 원래 위치로 돌아갑니다. 적 처치와 보물 발견은 선택입니다.

## 이미지와 동작

새 픽셀아트 아틀라스에서 어른 펭귄 30개 포즈, 아기 펭귄 8개 포즈, 적 16개 포즈, 물고기 12개 포즈와 탐험 오브젝트 12개를 불러옵니다. 슬라이딩과 수영은 각 6개 전용 프레임이며, 서 있는 펭귄을 회전시키던 표현을 대체했습니다. 아기 펭귄은 걷기, 눈 깜박임, 점프와 하강을 실제 포즈로 재생합니다. 물범은 경고/돌진, 갈매기는 4단계 날갯짓, 게는 발과 집게, 정령은 도약 준비/상승/하강을 표시합니다.

발끝 기준과 공통 배율을 사용해 프레임별 크기 변화와 발판 위의 틈을 줄였습니다. 일지, 둥지, 꽃밭, 레버 및 잠수 구멍도 같은 그림체로 맞췄고, 바닷속에는 새 남극 해저 배경을 적용했습니다. 생성 도구와 최종 프롬프트는 `pygame/data/ART-V2.md`에 기록되어 있습니다.

## 게임 창 크기

F2 키 또는 화면 오른쪽 아래의 'F2 창 크기' 버튼으로 크기 선택창을 엽니다. 640×480, 800×600, 1024×768, 1280×960 중 선택할 수 있습니다. 위아래 키와 Enter 또는 원하는 크기를 클릭해 적용하고, ESC나 F2로 닫습니다. 선택창이 열려 있는 동안 게임은 정지합니다.

창 가장자리를 드래그하거나 최대화할 수도 있습니다. 화면은 4:3 비율을 유지하며 여백을 표시하므로 펭귄과 UI가 늘어나거나 잘리지 않습니다. 크기를 바꿔도 진행 상황은 유지됩니다.


## UI와 잠수 화면

제목은 둥근 Jua, 본문은 Gowun Dodum 글꼴을 사용합니다. 글꼴과 SIL OFL 라이선스를 실행 파일에 포함하므로 다른 컴퓨터에서도 같은 한글 UI를 표시합니다.

잠수 중 수영 자세는 상승·하강에 따라 부드럽게 기울어집니다. 멈추면 느린 날갯짓과 작은 부유 동작으로 전환합니다. 물고기 수집 시 원형 파동과 반짝임이 나타납니다. 빛줄기, 수심 음영, 기포를 추가했고, 물고기를 중심 기준으로 그려 판정과 표시 위치를 맞췄습니다.

산소는 기존처럼 35초입니다. 출구까지 직선 이동 시간에 안전 여유를 더해 귀환 경고를 표시합니다. 하단 경로도의 초록 점은 출구, 작은 점들은 남은 물고기, 흰색 중심 표시는 펭귄입니다. 왼쪽 위 얼음 구멍 근처에서 E로 귀환합니다. 물고기 수집은 다음 잠수에도 이어지며, 산소가 끝나면 체크포인트로 돌아갑니다.
