# 펭귄의 남극 모험

남극의 물고기와 동료, 동굴 보물을 찾아 여러 결말에 도전하는 Pygame 플랫포머입니다.

## 조작

- `←` `→`: 이동 및 수영
- `Space`: 점프, 길게 누르면 더 높이 점프
- `↓`: 슬라이딩 또는 수영 하강
- `E`: 상호작용
- `Tab`: 탐험 일지
- `M`: 전체 소리 켜기/끄기
- `F3`: 점수 기록
- `F6`: 그래픽 품질
- `R`: 다시 시작 확인
- `Esc`: 종료 확인

지역마다 얼음 관성, 눈보라 바람, 붕괴 발판 같은 기믹과 별도의 환경음이 적용됩니다. 엔딩에서는 무피격, 무추락, 5분 이내 완료 여부도 확인할 수 있습니다.

3번째 지역 후반에는 거대 바다표범 보스가 등장합니다. 돌진 경고를 보고
피한 뒤, 보스가 빙벽에 부딪혀 기절했을 때 머리를 세 번 밟으면 통로가
열립니다.
