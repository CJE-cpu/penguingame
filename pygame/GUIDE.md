# 남극 펭귄의 물고기 모험

## 바로 실행

Windows에서 `pygame/AntarcticPenguin.exe`를 더블 클릭하세요. Python 설치 없이 실행되며 이미지가 포함되어 있습니다.

소스로 실행하려면 저장소의 최상위 폴더에서 다음 명령을 사용하세요.

```powershell
python -m pip install -r requirements.txt
python pygame/main.py
```

## 목표와 조작

물고기 30마리를 모으고 아기 펭귄 3마리를 이글루로 데려오면 성공합니다.

- Enter / 스페이스바: 설명 화면에서 시작
- ← → / A, D: 이동
- 스페이스바 / ↑ / W: 점프
- R: 전체 진행을 초기화하고 설명 화면으로 돌아가기
- Esc: 종료

## 여섯 탐험 구역

7,200픽셀의 맵을 서로 다른 지형과 배경으로 구성했습니다.

1. 눈 덮인 해안: 올라갔다 내려오는 능선과 바닷길
2. 미끄러운 빙하: 높이가 다른 얼음 섬과 높은 중앙 능선
3. 얼음 동굴: 안전한 아래 통로와 되돌아 올라가는 보물 탐험길
4. 눈보라 고원: 바람을 맞으며 올라가는 높은 지대
5. 갈라진 빙붕: 작은 섬과 무너지는 발판 다리
6. 펭귄의 보금자리: 넓은 해안과 갈라지는 위쪽 경로

얇은 발판은 아래에서 통과하고 위에서 착지할 수 있습니다. 이글루에 닿으면 현재 플레이의 복귀 지점이 저장됩니다. R을 누르거나 게임을 종료하면 진행이 초기화됩니다.

## 아이템과 점수

- 초록 성장 물약: 8초간 외형이 1.5배 커지고 접촉한 게를 물리칩니다. 이동 판정은 동일하므로 좁은 구간에서도 끼지 않습니다.
- 노랑 속도 물약: 8초간 이동 속도 1.6배
- 보라 반전 물약: 8초간 좌우 이동 반전
- 주황 물고기 10점, 파랑 25점, 황금 50점
- 게 처치 30점, 아기 펭귄 구조 100점, 동굴 보물 100점

미끄러운 얼음에서는 관성이 남고, 눈보라 구역의 바람은 왼쪽으로 밀어냅니다. 금이 간 발판은 밟고 0.8초 뒤 무너지고 4초 뒤 복구됩니다.

추락이나 피격 시 마지막 이글루로 돌아오며 점수는 유지됩니다. 아이템 효과는 사라지고 2초간 무적이 됩니다. 구조 중인 아기 펭귄은 원래 위치로 돌아갑니다. 적 처치와 보물 발견은 선택입니다.
