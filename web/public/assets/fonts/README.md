# Bundled Korean fonts

Jua (titles) and Gowun Dodum (body and labels) are distributed under the SIL Open Font License 1.1. The original license files are included alongside each font.

Source: https://github.com/google/fonts/tree/main/ofl/jua and https://github.com/google/fonts/tree/main/ofl/gowundodum

These files are bundled with the executable so the interface uses the same Korean typography on other computers.
